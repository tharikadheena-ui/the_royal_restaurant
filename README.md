# Restaurant Management System

A C-based console application that demonstrates data structures, algorithms, scheduling, and simulation for restaurant management.

## Features

- Customer seating management
- Priority-based waiting list
- Customer and order management
- Kitchen station scheduling
- Order prioritization
- Kitchen dependency graph
- Topological sorting
- Critical-path ETA calculation
- Event-based restaurant simulation
- Performance and simulation metrics

## Data Structures

- Generic Heap
- Linked List
- Hash Table
- Queue
- Graph / DAG

## Algorithms

- Heap operations
- Priority scheduling
- Best-fit seating
- Aging-based priority
- Shortest Job First
- Kahn's Topological Sort
- Critical Path Analysis

## Tech Stack

- C
- GCC
- Git
- GitHub
- VS Code
